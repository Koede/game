## How to run it in Leonardo

1. Open the image generator, choose the Pixel Art model, and open the **Image Guidance / Style Reference** panel.
2. Upload the day sprite for the character. Set the reference strength high enough to keep the face and hair, but not so high that it copies the outfit.
3. Paste the prompt below for that character and that outfit.
4. Generate 4, keep the one whose face and hair match the day sprite best.
5. Save it as a plain light-grey background (or remove it afterwards) at about 1000 px tall, and put it in assets/npcs/ with the name above.

## Shared style (add to every prompt)

> Pixel art full-body character sprite, front view, standing straight with arms relaxed, centred on a plain flat light-grey background, clean dark outlines, hand-placed pixels, cel shading with three to four tones, no dithering, no text, no watermark. Keep the exact face, hair, skin tone, eyes and build of the reference character. Wholesome, tasteful, family-friendly, ordinary clothing coverage, natural proportions, nothing emphasised.
